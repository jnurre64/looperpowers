### Interactive Goal policy

The shared project gates above also apply to Codex. Claude wakeups/monitors and timer hosting
are runtime-specific and are not required for native Goal. The clean-main/publication sequence
for scheduled iterations does not govern merely starting or pausing interactive work. Preserve
branch, staged/untracked files and unpublished commits; record local-only status when publishing
is not authorized. Existing explicit project publication requirements still govern affected
actions. Goal does not grant additional permissions. Pause records native state separately from
project readiness; a paused native Goal retains ownership until verified transfer.
